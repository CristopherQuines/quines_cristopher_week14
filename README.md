# Quines_Cristopher_Week14 — School Portal Static UI

## How to Preview Both Screens
1. Run `flutter pub get` and `flutter run`.
2. By default, `lib/main.dart` loads `LoginScreen()`.
3. To preview `WelcomeScreen()`, open `lib/main.dart`, comment out `home: const LoginScreen(),`, uncomment `home: const WelcomeScreen(),`, and trigger a Hot Restart (`Shift + R`).
